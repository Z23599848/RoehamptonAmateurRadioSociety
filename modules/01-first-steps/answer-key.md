## Worksheet

### Activity A

1. **Fits the purpose:** comparing antennas is technical learning.
2. **Does not fit:** allocating paid jobs is business traffic.
3. **Fits the purpose:** exchanging reception observations is a hobby/technical activity.

These classifications answer the purpose question only. Other licence conditions still apply to an actual transmission.

### Activity B

| Given frequency | Frequency in MHz | Range |
| --- | --- | --- |
| 7.1 MHz | 7.1 | HF |
| 14.2 MHz | 14.2 | HF |
| 100 MHz | 100 | VHF |
| 145 MHz | 145 | VHF |
| 435 MHz | 435 | UHF |
| 2.4 GHz | 2,400 | UHF |

VHF describes a broad spectrum range. Only specific parts are amateur allocations; a 100 MHz example does not become an amateur channel because it is VHF.

### Activity C

1. **6 Hz.** Count complete cycles in the stated second.
2. **Wavelength**, because the axis represents distance.
3. **Halves.** Wave speed was held constant.
4. About **21 m** near 14 MHz and about **2 m** near 145 MHz. Accept roughly 20–22 m and 1.9–2.2 m for this classroom chart-reading task; these are RARS teaching tolerances, not official marking rules.
5. About **150 MHz** from exactly 2 m. A coarse graph reading near this is reasonable. It is not an instruction to transmit at 150 MHz.
6. Band names are convenient approximations; frequencies vary across the band, so their wavelengths vary too.

Optional numerical check: 300 ÷ 145 ≈ **2.07 m**.

### Activity D

| Description | Term |
| --- | --- |
| Keyed carrier for Morse | CW |
| Speech represented digitally | Digital voice |
| Still picture transmitted slowly | SSTV |
| Instantaneous frequency varied by information | FM |
| One sideband, carrier suppressed | SSB |

The radio changed **mode**. Its displayed frequency and band did not change.
