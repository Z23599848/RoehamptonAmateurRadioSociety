## Activity A - Identify the change

An imaginary Foundation station uses the example call sign `M7ABC`.

1. It operates in Wales and chooses to include an RSL. Write the resulting call sign: ____________________.
2. It moves to Scotland and keeps using an RSL. What should change? ____________________.
3. Must an ordinary Foundation call sign always include an RSL? ____________________.
4. What is the exception for Intermediate call signs beginning with 2? ____________________.
5. Does adding `/P` extend the frequency or power permissions? ____________________.

A licensee changes their recorded address this month. Should they wait for the five-year revalidation date? Explain the action needed.

## Activity C - Purpose, message and place

For each suggestion, state the relevant rule rather than only saying yes or no.

1. Send an initial CQ call to find another amateur to talk to.
2. Send advertisements for a paid repair business on an amateur channel.
3. Use ordinary Morse, then claim that every coded message is forbidden encryption.
4. Operate a UK Foundation station while visiting France, without checking any other permission.
5. Transmit from a permitted aircraft at the usual ground-operation power just because the captain agreed.
