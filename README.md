# Roehampton Amateur Radio Society

Practical, beginner-friendly learning materials for RARS members preparing for the UK Amateur Radio Foundation examination.

## Start learning

**[Week 1: Your first steps in amateur radio](modules/01-first-steps/README.md)** is the first complete teaching draft. It includes a learner guide, classroom worksheet, tutor plan, original diagrams, a 12-question quiz and an explained answer key.

## Course status

Version 0.1 · 6 October 2026 · English · Independent RARS teaching material.

The first module was developed from the topics in an Essex Ham introductory transcript supplied by the course organiser, with fresh wording, examples, activities and questions. Technical and examination details were checked against current primary sources. This is not an Essex Ham, RSGB or Ofcom publication or endorsement.

The syllabus baseline is **RSGB v1.6b, March 2026 revision**. The linked Foundation reference booklet is **EX307, 22 January 2026**. Tutors should check the [RSGB specifications page](https://rsgb.org/main/clubs-training/for-trainers/syllabus-2019/) and [Ofcom licensing information](https://www.ofcom.org.uk/spectrum/radio-equipment/amateur-radio-info) before each new cohort.

Week 1 introduces a small part of the syllabus. Completion of this module does not establish readiness for the full examination. The rest of the course and a complete syllabus coverage review are still to be developed.
